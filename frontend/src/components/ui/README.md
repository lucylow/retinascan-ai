# UI Components

This directory contains reusable UI components built with shadcn/ui.

## 📦 Available Components

- **badge.tsx** - Badge component for labels and tags
- **button.tsx** - Button component with variants
- **card.tsx** - Card container component
- **progress.tsx** - Progress indicator component
- **toast.tsx** - Toast notification component
- **toaster.tsx** - Toast container component

## 🎨 Features

- Built on Radix UI primitives for accessibility
- Fully customizable with Tailwind CSS
- Type-safe with TypeScript
- Variants controlled by class-variance-authority

## 📖 Documentation

Full documentation at: https://ui.shadcn.com/

## 🔧 Adding New Components

To add a new shadcn/ui component:

```bash
npx shadcn-ui@latest add [component-name]
```

Components are automatically saved to this directory with proper imports.
